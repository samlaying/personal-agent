# ③ 过程性材料

中间产物的归档处：发散的、被否掉的、犹豫过的。**「为什么最后是这个方案」就体现在这里**，也是这个训练最有价值的证据。

## 三类子目录

| 目录 | 放什么 | 纪律 |
|---|---|---|
| `brainstorm/` | 发散：点子清单、与 AI 的讨论摘要、草稿 | 一次讨论一个文件，标注日期；只追加不修改，保持时间线 |
| `decisions/` | 收敛：关键取舍的决策记录（ADR 风格） | 一个决策一个文件 |
| `reviews/` | 评审：对抗性 Agent 的攻击与回应（预留，后续启用） | 一轮评审一个文件 |

被否掉的方案**不要删**，写进 decisions 的「选项」里并注明否掉理由。

## 决策记录模板

```markdown
# D-<编号> <决策标题>（<日期>）
- 背景：什么问题逼出了这个决策？
- 选项：列 2~3 个，各自代价
- 结论：选了什么
- 代价：接受放弃了什么
- 关联：链回 needs.md 第 X 条 / findings.md 第 X 条
```
